## 🇫🇷 Français

Un jeu de géopolitique et d'histoire multijoueur, gratuit, propulsé par l'IA. Choisis une nation, donne tes ordres et l'IA simule la réaction du monde. Sur téléphone et ordinateur, en 5 langues (français, anglais, espagnol, chinois, russe).

**Fonctionnalités**
- 🌍 **Vraie carte du monde** qui se prolonge à l'infini (fonds sombre, clair, rues, relief, satellite, villes). Clique sur un pays : drapeau, nom et fiche. Options de carte : modes d'affichage (propriétaire, continent, population, PIB), opacité, frontières.
- ✨ **Mondes inventés par l'IA** avec relief, montagnes, déserts, forêts, rivières, villes, drapeaux et attributs de jeu. Réglages : nombre de nations, niveau de la mer, relief, fragmentation.
- 📜 **Scénarios historiques**, la carte évolue selon les actions, événements du tour placés sur la carte.
- 🎓 **Mode éducatif** : choisis ta **classe** (primaire à terminale) ou **« culture générale »** si tu n'as plus d'école, puis une ou plusieurs **époques**. Tu avances année par année et tu découvres **dates, personnages, vocabulaire, anecdotes hors programme**, avec des quiz et un score. Tu peux tenter des **actions hors programme** : l'IA les compare à la vraie histoire. Les **sources** (programmes officiels, manuels, encyclopédies) sont affichées avec des liens de recherche. ⚠️ Le contenu est généré par une IA : vérifie toujours avec ton manuel.
- 🔊 **Narrateur IA optionnel** (voix du navigateur) : activable à tout moment, voix féminine ou masculine, vitesse réglable, dans toutes les langues du site.
- 👥 **Multijoueur** : prêts pour le tour suivant, l'hôte peut forcer le tour, exclure, fermer la partie. Paramètres de partie : nom, joueurs, durée d'un tour (1 mois à 25 ans), difficulté, nations IA.
- 💾 **Sauvegarde et diplomatie** : export / import d'une partie en fichier, l'IA retient les traités, alliances et rancunes d'un tour à l'autre, carte en plein écran, choix de la voix du système.
- 🎨 **Interface** : illustrations animées, **10 thèmes** (Océan, Parchemin, Nuit, Forêt, Rubis, Désert, Cyber, Aurore, Glace, Royal), menu latéral ☰ (accueil, parties, créer, éducatif, rejoindre, tutoriel, thèmes, réglages) et **chronique éditable** : chaque paragraphe terminé s'y range, l'hôte peut le modifier (✏️), chacun peut l'épingler (📌) dans son **carnet** personnel.
- 🎬 **Tour détaillé pas à pas** : chaque action est résolue séparément. Après le tour, la carte zoome sur chaque événement (zoom animé, frontières qui clignotent) pendant que le texte s'écrit à l'écran, avec pause, précédent et suivant. En mode éducatif, le récit du tour s'affiche automatiquement sous la carte. Tu peux écrire **plusieurs actions** par tour, les enregistrer et les supprimer une à une ; l'hôte peut aussi supprimer un paragraphe de la chronique. Les **10 thèmes** changent aussi les polices, les formes, les textures et le style de la carte.
- 🗣️ **Discussions entre nations** : messages publics ou privés entre joueurs, conversations avec les nations dirigées par l'IA (elles répondent en personnage, négocient, menacent et proposent des traités que tu acceptes ou refuses), bouton « avis des nations » et **coulisses diplomatiques** générées à chaque tour. Les messages privés entre joueurs sont masqués dans l'interface mais enregistrés dans la partie.
- 🤖 **IA au choix** : Gemini, OpenRouter, Groq (gratuits), OpenAI, Claude, Grok. Chacun utilise sa propre clé. Bouton « 🧪 Tester l'IA ».
- 🔐 **Connexion** : Google ou e-mail + mot de passe.

**Jouer** : ouvre le lien, connecte-toi, ⚙️ Réglages (pseudo, fournisseur d'IA, clé, modèle, thème, langue, narrateur), puis « Créer », « 🎓 Éducatif » ou « Rejoindre ».

**Règles** : **3 parties maximum** par compte ; **un seul compte par personne** (e-mail vérifié, alias comme `+test` ou points Gmail détectés, un appareil par compte dans une partie hors mode éducatif) ; après **7 jours d'inactivité**, un message te propose de garder la partie, et elle est supprimée après **14 jours** sans activité (aucun e-mail n'est envoyé). Tes parties sont sauvegardées sur ton compte et restent compatibles avec les mises à jour. Les autres joueurs ne voient que ton **pseudo**.

## 🇬🇧 English

A free multiplayer geopolitics and history game powered by AI. Pick a nation, give orders and the AI simulates how the world reacts. Works on phones and computers, in 5 languages (French, English, Spanish, Chinese, Russian).

**Features**
- 🌍 **Real world map** that wraps endlessly (dark, light, streets, terrain, satellite, cities). Click a country: flag, name and profile. Map options: display modes (owner, continent, population, GDP), opacity, borders.
- ✨ **AI-invented worlds** with terrain, mountains, deserts, forests, rivers, cities, flags and gameplay attributes. Settings: number of nations, sea level, relief, fragmentation.
- 📜 **Historical scenarios**, the map evolves with actions, the turn's events are placed on the map.
- 🎓 **Educational mode**: choose your **class** (primary to final year) or **"general knowledge"** if you're out of school, then one or more **eras**. Move year by year and discover **dates, key figures, vocabulary and extra off-curriculum facts**, with quizzes and a score. You can try **off-curriculum actions**: the AI compares them with real history. **Sources** (official curricula, textbooks, encyclopedias) are shown with search links. ⚠️ Content is AI-generated: always check with your textbook.
- 🔊 **Optional AI narrator** (browser voices): toggle any time, female or male voice, adjustable speed, in every site language.
- 👥 **Multiplayer**: ready for next turn, the host can force the turn, kick, close the game. Game settings: name, players, turn length (1 month to 25 years), difficulty, AI nations.
- 💾 **Saves and diplomacy**: export / import a game as a file, the AI remembers treaties, alliances and grudges from turn to turn, full-screen map, system voice choice.
- 🎨 **Interface**: animated illustrations, **10 themes** (Ocean, Parchment, Night, Forest, Ruby, Desert, Cyber, Aurora, Ice, Royal), side menu ☰ (home, games, create, educational, join, tutorial, themes, settings) and an **editable chronicle**: each finished paragraph is stored there, the host can edit it (✏️), everyone can pin it (📌) to a personal **notebook**.
- 🎬 **Step-by-step turns**: every action is resolved separately. After the turn the map zooms to each event (animated zoom, flashing borders) while the text is typed on screen, with pause, previous and next. In educational mode the turn's story appears automatically under the map. Write **several actions** per turn, save and delete them one by one; the host can also delete a chronicle paragraph. The **10 themes** also change fonts, shapes, textures and the map style.
- 🗣️ **Discussions between nations**: public or private messages between players, conversations with AI-run nations (they answer in character, negotiate, threaten and propose treaties you can accept or refuse), an "ask the nations" button and **diplomatic backstage** generated every turn. Private messages between players are hidden in the interface but stored in the game.
- 🤖 **Choose your AI**: Gemini, OpenRouter, Groq (free), OpenAI, Claude, Grok. Everyone uses their own key. "🧪 Test the AI" button.
- 🔐 **Sign-in**: Google or email + password.

**Play**: open the link, sign in, ⚙️ Settings (nickname, AI provider, key, model, theme, language, narrator), then "Create", "🎓 Educational" or "Join".

**Rules**: **maximum 3 games** per account; **one account per person** (verified email, aliases like `+test` and Gmail dots detected, one device per account in a game outside educational mode); after **7 days of inactivity** a message offers to keep the game, and it is deleted after **14 days** without activity (no email is sent). Your games are saved on your account and stay compatible with updates. Other players only see your **nickname**.

## 🇨🇳 中文

一款由 AI 驱动的免费多人地缘政治与历史游戏。选择一个国家、下达命令，AI 会模拟世界的反应。支持手机和电脑，提供 5 种语言（法语、英语、西班牙语、中文、俄语）。

**功能**
- 🌍 **可无限延伸的真实世界地图**（深色、浅色、街道、地形、卫星、城市）。点击国家查看国旗、名称和资料。地图选项：显示模式（所属国、大洲、人口、GDP）、不透明度、边界。
- ✨ **AI 虚构世界**：包含地形、山脉、沙漠、森林、河流、城市、国旗和游戏属性。可调整国家数量、海平面、地形起伏和碎片化程度。
- 📜 **历史情景**，地图会随行动变化，回合事件会标在地图上。
- 🎓 **教育模式**：选择你的**年级**（小学到高三），或选择**“通识”**（不再上学的人），再选择一个或多个**时代**。逐年推进，学习**日期、重要人物、词汇和课程之外的知识**，并通过测验获得积分。你可以尝试**课程之外的行动**：AI 会与真实历史对比。界面会显示**资料来源**（官方课程标准、教材、百科全书）及搜索链接。⚠️ 内容由 AI 生成，请务必对照课本核实。
- 🔊 **可选的 AI 旁白**（使用浏览器语音）：随时开关，可选女声或男声，可调语速，支持网站的所有语言。
- 👥 **多人游戏**：全员“已准备”后进入下一回合，房主可强制结束回合、移除玩家、关闭游戏。游戏设置：名称、玩家数、回合时长（1 个月到 25 年）、难度、AI 国家。
- 💾 **存档与外交**：可将游戏导出/导入为文件；AI 会记住各回合的条约、联盟和恩怨；全屏地图；可选择系统语音。
- 🎨 **界面**：动画插图、**10 种主题**、侧边菜单 ☰（首页、游戏、创建、教育、加入、教程、主题、设置）和**可编辑编年史**：每个完成的段落都会存入其中，房主可修改（✏️），每位玩家可将其钉到个人**笔记本**（📌）。
- 🎬 **逐步回合**：每个行动单独结算。回合结束后，地图会逐个缩放到各事件（动画缩放、边界闪烁），文字同步显示，可暂停、上一步、下一步。教育模式下，回合叙述会自动显示在地图下方。每回合可写**多个行动**，可逐个保存和删除；房主也可删除编年史中的段落。**10 种主题**还会改变字体、形状、纹理和地图风格。
- 🗣️ **国家之间的对话**：玩家之间的公开或私密消息；与 AI 国家对话（它们会以角色身份回应、谈判、威胁并提出你可接受或拒绝的条约）；“征求各国意见”按钮；每回合生成**外交幕后**内容。玩家之间的私密消息在界面中隐藏，但会保存在游戏中。

**开始**：打开链接并登录，在 ⚙️ 设置中填写昵称、AI 提供商、密钥、模型、主题、语言和旁白，然后选择“创建”、“🎓 教育”或“加入”。

**Возможности**
- 🌍 **Реальная карта мира**, которая продолжается бесконечно (тёмная, светлая, улицы, рельеф, спутник, города). Нажми на страну: флаг, название и справка. Настройки карты: режимы (владелец, континент, население, ВВП), прозрачность, границы.

Двигайся год за годом и узнавай **даты, ключевых персонажей, слова и факты вне программы**, проходи викторины и набирай очки. Можно пробовать **действия вне программы**: ИИ сравнит их с реальной историей. Показываются **источники** (официальные программы, учебники, энциклопедии) со ссылками для поиска. ⚠️ Контент создан ИИ: всегда сверяйся с учебником.

- 💾 **Сохранения и дипломатия**: экспорт / импорт игры в файл, ИИ помнит договоры, союзы и обиды от хода к ходу, полноэкранная карта, выбор системного голоса.

- 🎬 **Ход шаг за шагом**: каждое действие разрешается отдельно. После хода карта плавно приближается к каждому событию (анимация, мигающие границы), а текст печатается на экране; есть пауза, назад и вперёд. В обучающем режиме рассказ о ходе сам появляется под картой. Можно писать **несколько действий** за ход, сохранять и удалять их по одному; хозяин может удалить абзац хроники. **10 тем** меняют также шрифты, формы, текстуры и стиль карты.
- 🗣️ **Переговоры между нациями**: публичные и личные сообщения между игроками, разговоры с нациями под управлением ИИ (они отвечают в образе, торгуются, угрожают и предлагают договоры, которые можно принять или отклонить), кнопка «мнение наций» и **дипломатические кулуары** каждый ход. Личные сообщения между игроками скрыты в интерфейсе, но хранятся в игре.
- 🤖 **Выбор ИИ**: Gemini, OpenRouter, Groq (бесплатно), OpenAI, Claude, Grok. У каждого свой ключ. Кнопка «🧪 Проверить ИИ».
- 🔐 **Вход**: Google или e-mail + пароль.

**Как играть**: открой ссылку, войди, в ⚙️ Настройках укажи псевдоним, поставщика ИИ, ключ, модель, тему, язык и рассказчика, затем «Создать», «🎓 Обучение» или «Присоединиться».

**Правила**: **не более 3 игр** на аккаунт; **один аккаунт на человека** (подтверждённый e-mail, алиасы `+test` и точки в Gmail распознаются, на одном устройстве — один аккаунт в игре вне обучающего режима); через **7 дней без активности** появится предложение сохранить игру, а через **14 дней** без активности она удаляется (письма не отправляются). Игры сохраняются в аккаунте и остаются совместимыми с обновлениями. Другие игроки видят только твой **псевдоним**.

## Tutoriel d'installation · Self-hosting tutorial

Les règles Firestore sont communes aux deux tutoriels (Firestore → onglet **Règles** → tout remplacer → **Publier**) / The Firestore rules are shared by both tutorials (Firestore → **Rules** tab → replace everything → **Publish**):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read: if request.auth != null && request.auth.uid == uid;
      allow create, update: if request.auth != null && request.auth.uid == uid
        && request.resource.data.keys().hasOnly(['games','seen'])
        && request.resource.data.games.size() <= 3;
      allow delete: if false;
    }
    match /emails/{h} {
      allow get: if request.auth != null && (resource == null || resource.data.uid == request.auth.uid);
      allow create: if request.auth != null && request.resource.data.keys().hasOnly(['uid']) && request.resource.data.uid == request.auth.uid;
      allow update, delete, list: if false;
    }
    match /games/{code} {
      allow get: if request.auth != null;
      allow list: if false;
      allow create: if request.auth != null && request.resource.data.host == request.auth.uid
        && getAfter(/databases/$(database)/documents/users/$(request.auth.uid)).data.games.hasAny([code]);
      allow update: if request.auth != null;
      allow delete: if request.auth != null && (resource.data.host == request.auth.uid
        || request.time.toMillis() - resource.data.lastActive > 1209600000);
    }
  }
}
```
